# Fonts

Every font Phaedrus ships is under the SIL Open Font License 1.1 (OFL). They
come from `@fontsource` npm packages, each of which carries its own `LICENSE`
file in `node_modules`, and are bundled into the app (nothing is fetched at
runtime).

| Archivo | `@fontsource-variable/archivo` | OFL 1.1 | The Archivo Project Authors | Board, Tuner, Drive, Deck, Kissa (silkscreen labels), Pocket (printed legends) |
